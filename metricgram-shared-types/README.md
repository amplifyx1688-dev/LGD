# Shared Types for Metricgram

This package contains TypeScript type definitions shared between frontend and backend.

## Installation

```bash
npm install @metricgram/shared-types
```

## Usage

```typescript
import {
  User,
  Group,
  DiceGame,
  ModuleType,
  ContentItem,
  ButtonConfig
} from '@metricgram/shared-types';
```

## Development

```bash
npm run build
npm run dev  # watch mode
```
